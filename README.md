# Localhost

**Tech happens IRL.** The event platform built only for tech: meetups, hackathons, conferences, summits, demo days and launch parties, in San Francisco, New York, London, Berlin, Kigali, Cape Town, Lagos, Nairobi and wherever people build.

- `index.html` — landing page
- `event.html` — sample event page
- [`CONCEPT.md`](CONCEPT.md) — brand, positioning, product, business model, go-to-market and MVP scope

Static site, no build step. Open `index.html` in a browser or serve the folder:

```sh
python3 -m http.server 8000
```

All events, people, communities and numbers on the pages are sample data.
